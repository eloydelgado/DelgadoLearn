# Comunidad

En DelgadoLearn fomentamos la colaboración, el aprendizaje mutuo y la construcción comunitaria.

## 💬 Cómo Participar

### GitHub Discussions
Abre una discusión para:
- Hacer preguntas sobre contenido
- Compartir experiencias de aprendizaje
- Proponer nuevos temas o cursos
- Dar feedback general

[→ Ir a Discussions](https://github.com/delgadolearn/delgadolearn/discussions)

### Issues
Reporta problemas técnicos o sugerencias de contenido:
- Errores en documentación
- Enlaces rotos
- Contenido desactualizado
- Sugerencias de mejora

[→ Reportar Issue](https://github.com/delgadolearn/delgadolearn/issues)

### Pull Requests
¡Contribuye directamente! Ver [Guía de Contribución](contributing.md)

## 🏆 Reconocimiento

Valoramos toda contribución. Los colaboradores activos serán reconocidos en:
- Lista de contribuidores del proyecto
- Mención especial en actualizaciones importantes
- Acceso a discusiones privadas (si aplica)

## 📢 Código de Conducta

DelgadoLearn es un espacio inclusivo y respetuoso. Esperamos:

✅ **Respeto mutuo** - Trata a otros con cortesía
✅ **Inclusión** - Bienvenemos perspectivas diversas
✅ **Constructivismo** - Feedback positivo y útil
✅ **Confidencialidad** - Respeta información privada

❌ **No toleramos**: Discriminación, acoso, spam, o contenido ofensivo
